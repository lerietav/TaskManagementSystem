# Task Management System — Java ☕

A Java-based task management system developed to apply object-oriented programming, data structures, and algorithms in a practical business scenario.

## 📌 About the project

The system allows users to manage and organize tasks and employees through a menu-driven console application.

The project was designed to explore different data structures and algorithms and how they can be applied to solve organizational and task-management problems.

## 🧩 Data Structures

The system implements several data structures, including:

- 📚 Stack — task management using `PilaTareas`
- 📝 Queue — task management using `ColaTareas`
- ⭐ Priority Queue — prioritization of tasks
- 🔗 Linked List — task organization using `ListaTareas`
- 🌳 Binary Search Tree — employee organization using `ArbolEmpleadosBST`
- 🕸️ Graph — task dependency management using `GrafoDependencias`

## 💻 Technologies

## ⚙️ Features

## ▶️ How to run

Make sure Java is installed on your computer.

1. Clone the repository

git clone https://github.com/lerietav/Task-Management-System-Java.git

2. Navigate to the project folder

cd Task-Management-System-Java

3. Compile the source files

javac -d out src/*.java

4. Run the application

java -cp out Main

The application will start with an interactive console menu.
